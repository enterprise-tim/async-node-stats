# AsyncLocalStorage Performance Results

GitHub Pages site for displaying AsyncLocalStorage benchmark results across Node.js versions.

## Overview

This project provides a comprehensive visualization of AsyncLocalStorage performance analysis across different Node.js versions, helping developers understand the performance implications of using AsyncLocalStorage in their applications.

## Features

- **Performance Analysis**: View AsyncLocalStorage overhead across Node.js versions
- **Memory Analysis**: Analyze memory usage patterns and detect potential leaks
- **Interactive Charts**: Visualize performance data with Chart.js
- **Version Comparison**: Compare results across Node.js 16.20.2 through 24.6.0
- **GitHub Pages Ready**: Deploy directly to GitHub Pages for easy sharing

## React App

The React application provides an interactive interface to explore the benchmark results:

- **Overview**: Summary of all benchmark results
- **Performance**: Performance comparison charts across Node.js versions
- **Memory**: Memory usage analysis and comparison
- **Version Analysis**: Detailed analysis of specific versions
- **Recommendations**: Best practices and usage recommendations

### Data Loading

The app loads benchmark data from external sources:

1. **External Data**: Benchmark results are loaded from centralized data endpoints
2. **Automatic Updates**: Data is refreshed when the page loads
3. **Error Handling**: Graceful fallbacks when data is unavailable

### Chart Components

- **PerformanceChart**: Displays performance overhead comparisons
- **MemoryChart**: Shows memory usage patterns
- **Toggle between line and bar charts**
- **Responsive design** for different screen sizes

## Development

### Prerequisites

- Node.js 16.0.0 or higher
- npm or yarn

### Setup

```bash
# Clone the repository
git clone https://github.com/tobrien/async-node-stats.git
cd async-node-stats

# Install dependencies
npm install

# Download latest benchmark data (optional but recommended)
npm run download-benchmarks

# Start development server
npm run dev
```

The app will be available at `http://localhost:5173` (or the next available port).

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run deploy` - Deploy to GitHub Pages
- `npm run download-benchmarks` - Download latest benchmark data from als-benchmark-basic
- `npm run build-with-data` - Download benchmark data and build for production

### Local Development with Real Data

To develop with actual benchmark data:

```bash
# Download the latest benchmark results
npm run download-benchmarks

# Start development server with real data
npm run dev
```

This will download the latest benchmark results from the `enterprise-tim/als-benchmark-basic` repository and make them available to the development server.

### Building

```bash
# Build for production
npm run build

# Build with latest benchmark data
npm run build-with-data

# Preview production build
npm run preview
```

## Deployment

### GitHub Pages

The app is configured for GitHub Pages deployment:

1. **Base Path**: Configured for `/async-node-stats/` repository path
2. **Static Assets**: All assets are served as static files
3. **SPA Routing**: Handles client-side routing properly

### Manual Deployment

To deploy to other static hosting:

1. Run `npm run build`
2. Upload the `dist/` directory contents
3. Ensure the external data sources are accessible
4. Update the base path in `vite.config.js` if needed

## Data Sources

This site displays benchmark results that are generated by the [als-benchmark-basic](https://github.com/enterprise-tim/als-benchmark-basic) repository. The data includes:

- Performance overhead measurements across Node.js versions
- Memory usage analysis and comparison
- Distributed system performance testing
- Version-to-version performance evolution

The site automatically downloads the latest benchmark results from the `enterprise-tim/als-benchmark-basic` repository releases and displays them in an interactive format.

For information about running benchmarks, please refer to the [als-benchmark-basic repository](https://github.com/enterprise-tim/als-benchmark-basic).
